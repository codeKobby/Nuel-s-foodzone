# Nuel’s Foodzone Reference-Led Redesign

## Approved brand line

> Your home of quality delicacies.

This line replaces “Food with feeling” across the public website. It should appear in the brand hero, public shell metadata, footer, and the Dinner/Catering story where appropriate.

## Direction from the supplied references

The supplied references share a clear service-brand pattern: a bright off-white canvas, high-contrast charcoal type, a warm orange conversion accent, compact rounded cards, visible trust metrics, a concise “how it works” sequence, food-led product cards, and event/catering sections supported by photography. They are more polished and commercial than the previous editorial redesign, while still feeling premium.

Nuel’s Foodzone should use this pattern without copying any reference. The home page should introduce the brand with a light, spacious hero that places the slogan and order actions beside a clean food composition. A small metrics strip should establish trust. A four-step process should explain ordering and receipt flow. Featured Dinner dishes should use compact food cards with price and clear actions. Catering should be represented with an event gallery and enquiry CTA. Reviews and a final order band should close the page.

## Visual tokens

The base canvas is warm white `#fffdf9` with pale cream sections `#fff5e9`. Charcoal `#242323` carries the primary text. Tomato-orange `#f15b2a` is the main action color, with a darker burnt-orange hover state. A controlled leaf green `#2f7d4f` supports Catering and quality cues. Cards use 16px–20px radii, soft borders, and restrained shadows. Buttons use 10px–12px radii and should remain compact rather than pill-shaped.

Typography should be one friendly sans-serif family with strong weight contrast, not a decorative display serif. Headlines should use sentence case, short lines, and readable line lengths. Copy should feel direct and service-oriented: what we make, how ordering works, what customers can expect, and how to start Catering.

## Local verification

The new home page now follows the supplied reference structure: bright cream canvas, orange action color, readable sans-serif hierarchy, a two-column food-led hero, compact trust cards, a four-step “How it works” section, featured Dinner cards, and a Catering/event section. The approved slogan is visible in the hero, header, and footer.

The Catering page carries the same system with a green service hero, orange conversion actions, event-type cards, three clear service steps, and an enquiry close. Both pages rendered successfully in the local browser after the clean build and development-server restart.
